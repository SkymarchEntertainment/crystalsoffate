# Crystals of Fate website

Static landing page for [Crystals of Fate](https://www.crystalsoffate.com/), served with GitHub Pages from the `main` branch root.

- `index.html`, `css/styles.css`, `js/main.js`: the whole site, no build step
- `assets/img/hero.webp`: key art with the logo; tagline and download buttons are real HTML laid over it

Preview locally:

```bash
python -m http.server 4173
```
